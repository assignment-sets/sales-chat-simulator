# Frontend & UI Architecture Rules

1. **Component-First Design**: When building any UI feature, extract and construct reusable components (`components/ui/`, `components/chat/`, etc.) first before assembling page layouts.
2. **Minimal & Clutter-Free UI**: Never overwhelm the user with walls of text, dense instructional paragraphs, duplicate buttons, bloated placeholders, or cramped spacing. Keep copy crisp, minimal, and non-intimidating.
3. **Zero Layout Shifts**: Never render expanding inline error/message banners that alter container shapes or heights. Use the centralized toast utility (`lib/toast.ts`) for all user feedback.
4. **Standard 3-Dot Loader**: Use the shared 3-dot loader component (`components/ui/Loader.tsx`) for loading states, async actions, and screen transitions (`loading.tsx`).
5. **Strictly No Pill / Eyebrow / AI Badges**: Never add floating rounded pill badges, eyebrow capsules (e.g. `rounded-full bg-zinc-100`, `bg-*-50 border border-*-200`), sparkle badges (`<Sparkles>` pill), or decorative status tags floating above titles and headings anywhere across the frontend. If context or hierarchy must be conveyed, express it directly through clean typography (e.g., standard sentence-case headings, subtle editorial numbering, or understated subtitle text)—never as a pill badge.
6. **Strictly No Pastel / Candy Alert Callout Boxes (Anti-AI-Slop Callouts)**: Never render colorful pastel callout boxes (e.g. `bg-emerald-50`, `bg-amber-50`, `bg-blue-50`, `bg-red-50` with saturated colored borders and colored icons) to highlight notices, commitments, disclaimers, or advice. These candy containers look like generic AI boilerplate slop. Instead, communicate emphasis using standard executive typography: clean monochrome cards (`bg-zinc-50 border border-zinc-200/80 rounded-2xl p-5`) with dark text (`text-zinc-900` title, `text-zinc-600` body) and neutral icons (`text-zinc-700` or `text-zinc-900`), or clean editorial accents. Keep public, legal, and documentation pages looking authoritative, refined, and human-crafted.
